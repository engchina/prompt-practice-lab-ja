# prompt-practice-lab-ja

OpenAIとAnthropicの公式ガイドをもとに、OpenAI互換LLMでプロンプトを書き、出力を比べながら学ぶ日本語の全10課。

[プロジェクトをダウンロードする（prompt-practice-lab-ja.zip）](https://github.com/engchina/prompt-practice-lab-ja/releases/latest/download/prompt-practice-lab-ja.zip)

## 始め方

Node.js 22以上、Python 3.11以上、uv、利用するモデルのIDを用意します。以下はプロジェクトのルートで実行します。

```sh
npm --prefix web ci
uv sync --project api --locked
```

ターミナルを2つ開き、それぞれで起動します。

```sh
uv run --project api uvicorn main:app --app-dir api --host 127.0.0.1 --port 8710
```

```sh
node web/node_modules/next/dist/bin/next dev web --hostname 127.0.0.1 --port 3710
```

[訓練場を開く](http://127.0.0.1:3710)。左の「設定」でベースURL、モデルID、必要に応じてAPIキーを入力します。OpenAIの場合は `https://api.openai.com/v1`、ローカルの互換サーバーなら例として `http://127.0.0.1:1234/v1` を使います。モデルIDは接続先が提供する名称です。アプリが末尾に `/chat/completions` を付けます。外部接続先にはHTTPSを使用します。個人のPCで動かす構成です。

## 第1課の進め方

1. レッスン一覧で第1課を開き、「まとめて。」のまま初稿Aを実行します。
2. 改善稿Bに切り替えます。同じ会議メモを使い、次の当番が必要とする列、担当が分からないときの書き方を指定して実行します。左の「背景と教材」に改善例があります。スマートフォンでは同名のボタンで開きます。
3. 「出力比較」で、田中が担当する作業と未定の作業を区別できたか確認します。それぞれの実行時の指示・入力・モデルも確認できます。
4. 「決定カード」に採用する案と理由を書きます。応用課題を試して修了し、次の課に進みます。

初稿・改善稿・各案の直近の結果・決定カード・進捗はブラウザのローカルストレージに自動保存します。同じ案の再実行は結果を更新するため、応用課題の前に比較の所見をカードに記録します。APIキーはタブのメモリに保持し、再読み込み後に入力し直します。教材の閲覧・下書きは接続設定の前から利用できます。

比較画面では、役割・入力資料・接続先・モデルが両案で異なる場合にお知らせします。指示の効果だけを調べるときは同じ条件で実行します。モデル移行を試す第9課では、意図して変えた条件を決定カードに記録します。

## 全10課と公式手法の対応

対象は下記の指定2ページの本文（2026年11月21日確認）。各モデルの個別ガイドや別ページの全API仕様は追加の読み物です。手法を調べ直せるよう、以下の表は公式ページの節と演習内容を対応づけています。

| 課 | 演習 | 対応する本文の手法 |
|---|---|---|
| 1 | 会議の引き継ぎ | Anthropicの直接的な指示、背景、役割、モデルの自己識別。OpenAIのsystemとuserの役割分担 |
| 2 | 問い合わせ分類 | 両社のfew-shot。典型例と境界例、XMLによる例の分離、OpenAIのYAML風ブロック・箇条書き |
| 3 | 新旧規程の照会 | AnthropicのXML構造、複数資料のメタデータ、長文の配置、引用抽出から結論を作る手順 |
| 4 | チケットのJSON化 | Anthropicの口調・長さ・形式制御、LaTeX、文書作成、前置き・継続・役割・誤解への対処を含むプリフィル移行 |
| 5 | 制約付きの会場選定 | Anthropicの思考量、過度の探索、思考とツール結果の交互利用、effort、例示、結果の再検証 |
| 6 | 予約の実行計画 | Anthropicのツール利用、実行と提案の選択、独立呼び出しの並列化、自律性・安全性、支払い・本人識別情報・財務記録 |
| 7 | 調査の引き継ぎ | Anthropicの長期推論、文脈残量、複数ウィンドウ、状態追跡、調査と仮説検証、サブエージェント、プロンプトチェーン |
| 8 | UIの不具合レビュー | Anthropicのファイル作成の抑制、過剰実装、テストへのハードコード、未読コードの推測、視覚入力とフロントエンド設計。分野別指示の例として製品ラベルの確認も扱う |
| 9 | 移行と回帰評価 | OpenAIのキャッシュ、フォルダー、名前付きモジュール、型付き引数、Responses APIへの受け渡し、プロンプトIDの移行、PR・評価・リリース・切り戻し。Anthropicのモデル別ガイド、品質・機能の指定、思考設定、プリフィル、強調の調整、追記型履歴と移行 |
| 10 | 根拠付き受付プロンプトの制作 | 両社の手法を統合。通常・例外・根拠不足の3ケースを評価し、採用版と適用限界を決定カードに残す |

通常の実行経路はテキストのChat Completionsです。ツールの実行順序、委任、画像の読み取り、モデル固有の思考設定、キャッシュ、デプロイについては、教材と設計演習で学びます。第8課では画面の文字起こしを使います。修了は学習者自身の評価です。

## 実装とライセンス

[engchina/no.1-ui-standard-lab](https://github.com/engchina/no.1-ui-standard-lab) のコミット `cd8e079b08a2e275af79bba54af2152b1d384ed7` を参照し、AppShell、サイドナビ、表、教材パネル、狭い画面のドロワー、タブと決定カードを使っています。元のMITライセンスを同梱しています。

- `web/` — Next.js 16、React 19、TypeScript、Astryx、StyleX、Chocolateテーマと共通CSS。APIへの転送先は環境変数 `LAB_API_URL` で変更できます。
- `web/src/lib/lessons.json` — 各課の教材、入力、初稿、改善例、評価基準、応用課題。
- `web/src/lib/extensions.json` — 各課で読み進める応用手法。
- `api/` — FastAPIが指定された互換サーバーへリクエストを中継します。キーをファイルに書き込みません。
